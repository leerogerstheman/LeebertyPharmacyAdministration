# 11 GxP质量管理体系

> 主题：GxP 概念总览（GLP/GCP/GMP/GSP/GVP/GAP/GDP/GPP 等）、各规范核心要求、共同内核与药品生命周期映射。
> 提示：各 GxP 具体条款以现行有效版本为准（如 GCP 2020、GMP 2010年修订、GSP 2016年修正、GVP 2021）。

## 一、GxP 概念

**GxP** 是 "Good x Practice"（良好…规范/实践）的统称，X 代表不同业务领域。GxP 指药品、医疗器械等健康产品全生命周期（研发、临床、生产、流通、使用、上市后监测）各环节应遵循的良好规范体系，大多以**法规、部门规章或国际指南**的形式发布，是质量合规的基本准则。

GxP 的本质：把经过验证的、可追溯的良好实践经验，固化为强制或推荐的管理规范，并通过**体系化、文件化、数据化**的方式落实。

## 二、主要 GxP 一览

| 简称 | 全称 | 中国主要法规（现行） | 适用环节 | 核心要求 |
|---|---|---|---|---|
| GAP | 中药材生产质量管理规范 | 《中药材生产质量管理规范》 | 中药材种植养殖 | 种子种苗、种植加工、产地环境、追溯 |
| GLP | 药物非临床研究质量管理规范 | 《药物非临床研究质量管理规范》（2023） | 非临床安全性评价（毒理/药理） | 机构与人员、设施、实验系统、SOP、质量保证部门（QAU）、原始数据真实完整 |
| GCP | 药物临床试验质量管理规范 | 《药物临床试验质量管理规范》（2020，接轨 ICH GCP E6(R2)） | 临床试验 | 受试者保护、伦理审查、知情同意、数据真实、监查/稽查、文档管理 |
| GMP | 药品生产质量管理规范 | 《药品生产质量管理规范》（2010年修订+附录） | 药品生产 | 质量风险管理、洁净环境、验证、数据完整性、质量受权人放行 |
| GSP | 药品经营质量管理规范 | 《药品经营质量管理规范》（2016修正） | 药品批发/零售/流通 | 质量管理体系、采购验收储存养护销售运输、追溯 |
| GVP | 药物警戒质量管理规范 | 《药物警戒质量管理规范》（2021年12月1日施行） | 上市后药物警戒 | 警戒体系、不良反应收集报告、信号检测、风险管理计划 |

## 三、GxP 的共同内核（“GxP 精神”）

无论哪个 X，共同的管理内核包括：

1. **质量管理体系（QMS）**：质量方针、组织机构、职责权限、资源配置；
2. **文件化体系**：管理文件、SOP、记录——"没有记录就没有发生"；
3. **数据完整性**：ALCOA+ 原则（可归属、清晰、同步、原始、准确 + 完整、一致、持久、可获得）；
4. **人员培训**：岗前 + 持续培训、资质认定、培训档案；
5. **设施设备确认与验证**：URS → DQ/IQ/OQ/PQ；环境监控、计算机化系统验证；
6. **风险管控**：ICH Q9 质量风险管理（识别→评估→控制→沟通→回顾）；
7. **偏差、变更与 CAPA**：闭环管理、根因分析；
8. **自查/审计**：内部审计、供应商审计、接受外部检查；
9. **持续改进**：质量回顾、质量量度、管理评审。

## 四、药品生命周期与 GxP 映射

```
药材( GAP ) → 非临床研究( GLP ) → 临床试验( GCP + CRA/CRC ) → 生产( GMP )
→ 流通( GSP / GDP ) → 使用( GPP / 药学服务 ) → 上市后监测( GVP )
                         ↑________________ 药物警戒覆盖全生命周期 ________________↑
```

- 研制注册阶段：GLP（安全性）、GCP（有效性/安全性证据）；
- 生产阶段：GMP（质量与工艺）；
- 经营流通：GSP（采购、储存、养护、运输、追溯）；
- 使用阶段：医疗机构药事管理、药学服务规范（GPP）；
- 上市后：GVP（药物警戒）与上市后研究（IV期、真实世界研究）。

## 五、企业 GxP 合规体系搭建（实操要点）

1. **差距分析**：对照适用的 GxP 条款逐条自查（可用各规范附录检查表）；
2. **体系建设**：写文件→培训→执行→记录→内审→改进（PDCA）；
3. **关键岗位**：质量负责人/质量受权人（GMP）、药物警戒负责人（GVP）、数据负责人；
4. **迎接检查**：飞行检查、GMP/GSP 符合性检查、注册核查（GCP/GLP）；
5. **检查常见缺陷**：数据完整性、验证不充分、偏差调查不闭环、文件与实际不符、培训流于形式。

## 六、GxP 相关常见考点/自查要点

- GxP 各规范分别管哪个环节（GAP-GLP-GCP-GMP-GSP-GVP 排序）；
- 数据完整性 ALCOA+ 的逐字母含义；
- QA 与 QC 的关系（QA=体系过程保证，QC=检验结果控制）；
- 偏差/变更/CAPA 闭环的流程；
- 验证四阶段 IQ/OQ/PQ（以及 DQ 设计确认）的顺序意义；
- ICH Q9 风险管理与 ICH Q10 质量体系在 GMP 中的地位。
