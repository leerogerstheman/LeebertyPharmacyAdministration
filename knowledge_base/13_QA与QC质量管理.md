# 13 QA与QC质量管理

> 主题：质量保证（QA）与质量控制（QC）的定义、区别、核心职能、质量体系文件、偏差变更 CAPA、数据完整性、岗位发展。
> 参考：ICH Q10 药品质量体系、《药品生产质量管理规范》相关章节等。

## 一、QA 与 QC 的定义

### 1.1 质量保证（QA，Quality Assurance）
通过**系统性、预防性**活动（体系建设、流程设计、审核改进），确保产品或服务**被正确地做出来**。QA 是**过程导向**的：关注"体系的健壮性"，保证每一步操作按规范执行，从而预防质量问题的发生。

### 1.2 质量控制（QC，Quality Control）
通过**检验、检测与判定**，确保产品**符合规定的质量标准**后才能放行。QC 是**产品导向**的：关注"结果是否正确"，通过取样、检验、判定实现把关。

### 1.3 一句话区分
- QA：保证质量**会**被实现（做对过程、防患未然）；
- QC：证明质量**已经**实现（检对结果、发现缺陷）；
- 经典语境："QA 不能由 QC 替代，QC 是 QA 的最后一道防线"。

## 二、QA 与 QC 职能对照表

| 维度 | QA（质量保证） | QC（质量控制） |
|---|---|---|
| 导向 | 过程/体系 | 产品/结果 |
| 时机 | 事先预防 + 过程监督 | 事中/事后检验 |
| 主要活动 | 文件体系管理、偏差/变更、CAPA、内审、供应商审计、培训、质量回顾、放行审核 | 取样、检验、留样、稳定性、环境监测、OOS 调查、仪器校准 |
| 输出 | 程序、记录、审核报告、改进措施 | 检验报告（COA）、放行判定数据 |
| 典型岗位 | QA 工程师/经理、质量审计员、合规专员 | QC 检验员/主管、微生物化验员、仪器分析员 |
| 与检查关系 | 直接对接药监检查（体系层面） | 提供检验证据（数据层面） |

## 三、QA 核心职能（展开）

1. **质量管理体系文件管理**：起草、审核、批准、分发、培训、生效、复审、变更、归档（受控文件）；
2. **变更控制（Change Control）**：评估影响→批准→实施→验证→关闭；
3. **偏差管理（Deviation）**：发现→报告→评估分类（重大/主要/微小）→调查根因→CAPA→关闭；
4. **CAPA（纠正与预防措施）**：纠正（立即消除）、预防（根因消除）、有效性评估；
5. **内部审计/自检**：按计划开展 GMP/GSP 自检，输出报告与整改跟踪；
6. **供应商与受托方审计**：准入评估、现场审计、年度绩效评价；
7. **培训管理**：岗位资质矩阵、培训计划、考核与档案；
8. **质量回顾**：年度质量回顾（PQR）/产品质量回顾，趋势分析与改进；
9. **风险管理**：组织风险评估（FMEA、HACCP、风险矩阵）；
10. **投诉与召回**：投诉调查处理、召回组织与模拟召回；
11. **验证管理**：验证主计划 VMP、验证方案/报告审核、再验证管理；
12. **计算机化系统合规**：CSV（计算机化系统验证）、权限、审计追踪、数据备份。

## 四、QC 核心职能（展开）

1. **取样**：按取样规程（SOP）代表性与均匀性取样，取样记录；
2. **检验**：原辅料、包装材料、中间产品、成品检验（理化、微生物限度/无菌、生物检定/效价、杂质谱）；
3. **环境监测**：洁净区悬浮粒子、浮游菌、沉降菌、表面微生物（GMP 附录要求）；
4. **留样与稳定性**：留样管理、长期/加速/影响因素试验、持续稳定性考察计划；
5. **OOS/OOT 调查**：超标结果（OOS）与超趋势（OOT）——先实验室调查（算术/操作/仪器），再扩大调查（取样、工艺），结论影响批次放行；
6. **方法验证与转移**：专属性、精密度、准确度、线性、范围、耐用性等验证项目；
7. **标准品/对照品**：来源、标定、储存、有效期管理；
8. **仪器管理**：校准（外校/内校）、确认（IQ/OQ/PQ）、预防性维护；
9. **数据与记录**：原始记录即时填写、电子数据完整性、图谱与积分参数受控；
10. **COA 出具**：检验报告书数据正确性、放行数据包完整性。

## 五、质量体系文件层级（文件金字塔）

```
第一层 质量手册（方针、目标、体系概述）
第二层 程序文件（跨部门流程：偏差/变更/CAPA/内审/培训…）
第三层 操作规程 SOP / 质量标准 / 工艺规程
第四层 记录/表单（检验记录、批记录、台账、日志）
```

- 文件生命周期：起草→审核→批准→培训→生效→受控分发→定期复审→变更→旧版回收归档；
- 文件编写原则：5W1H、可执行、可追溯；"写你所做、做你所写、记你所做"。

## 六、关键质量工具速查

| 工具 | 用途 |
|---|---|
| PDCA | 持续改进循环（计划-执行-检查-处理） |
| 鱼骨图 / 5Why | 根因分析 |
| 8D 报告 | 复杂问题系统性解决 |
| FMEA（失效模式与影响分析） | 风险识别（设计/工艺） |
| 控制图（SPC） | 过程稳定性监控 |
| 帕累托图 | 抓主要矛盾（80/20） |
| 风险矩阵 | 严重度×可能性定级 |
| 确认四阶段 | DQ→IQ→OQ→PQ（设计/安装/运行/性能确认） |

## 七、数据完整性（Data Integrity）要点

- **ALCOA+**：可归属 Attributable、清晰 Legible、同步 Contemporaneous、原始 Original、准确 Accurate；+ 完整 Complete、一致 Consistent、持久 Enduring、可获得 Available；
- 电子记录：权限分级、审计追踪（不可关闭）、电子签名、时间戳；
- 管理要求：数据治理体系（数据生命周期）、原始数据保留、备份与恢复演练；
- 检查关注点：手写记录补记、图谱重积分、账号共用、删除数据行为。

## 九、自查要点（企业 QA/QC 迎检常用）

☐ 质量手册/程序文件/SOP 现行有效、与实际一致；
☐ 偏差/变更/CAPA 台账齐全、闭环；
☐ 年度内审已执行且有整改；
☐ QC 检验记录真实完整（含原始图谱、积分参数）；
☐ OOS/OOT 调查记录完整、结论明确；
☐ 留样与稳定性计划落实；
☐ 仪器校准、环境监测数据可追溯；
☐ 计算机化系统权限与审计追踪正常；
☐ 培训档案与资质矩阵吻合；
☐ 质量回顾报告年度输出。
