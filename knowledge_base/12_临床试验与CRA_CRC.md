# 12 临床试验与 CRA·CRC

> 主题：药物临床试验法规与分期、试验团队角色分工、CRA（监查员）与 CRC（协调员）核心职责、监查/稽查区别、数据与 SAE 报告要点。
> 参考：《药物临床试验质量管理规范》（2020年第57号公告，实施日期2020年7月1日）、ICH E6(R2)《药物临床试验管理规范》。

## 一、药物临床试验概述

- **定义**：以人体（受试者）为对象，评价药物安全性、有效性的系统性研究。
- **法规依据**：GCP（2020版）、《药品注册管理办法》（2020）、伦理审查办法等；国际参照 ICH E6(R2)。
- **审批**：临床试验默示许可（受理后60个工作日内未否定即默认同意）；药物临床试验机构备案制；伦理委员会审查前置（知情同意书须伦理批准）。
- **注册分类**：I 期（耐受性/药代动力学）、II 期（初步疗效/剂量探索）、III 期（确证性疗效与安全性）、IV 期（上市后研究）；另有生物等效性试验（BE）、桥接试验等。
- **保护受试者核心原则**：伦理审查 + 知情同意 + 利益冲突管理 + 保险/赔偿。

## 二、临床试验团队与角色分工

| 角色 | 所属 | 核心职责 |
|---|---|---|
| 申办者（Sponsor） | 药品上市许可持有人/申请人 | 组织发起、质量与合规责任、监查与稽查责任 |
| CRO（合同研究组织） | 受托方 | 承接监查、数据管理、统计、医学等外包职能 |
| 研究者（PI 主要研究者/Sub-I 副研究者） | 医疗机构 | 临床决策与医疗责任，知情同意执行人，数据可靠性负责人 |
| **CRA 临床研究监查员** | 申办者/CRO | 监查中心质量，源数据核验、依从性监督 |
| **CRC 临床研究协调员** | 机构/第三方（SMO） | 协助研究者完成非医疗决策性事务 |
| DM 数据管理员 | 申办者/CRO | EDC 建库、数据清理、质疑管理 |
| 生物统计师 | 申办者/CRO | 方案统计设计、SAP、统计分析 |
| 医学监查员（MM） | 申办者/CRO | 医学合理性审查、安全性评估支持 |
| QA（临床质量保证） | 申办者 | 独立稽查、体系审计 |

## 三、CRA（Clinical Research Associate）核心职责

### 3.1 中心筛选与启动（SSU）
1. 中心筛选评估（机构资质、病源量、设备、PI 经验）；
2. 伦理与机构立项材料准备、合同谈判；
3. 启动会（SIV）：方案培训、GCP 培训、角色分工确认。

### 3.2 常规监查（On-site Monitoring）
1. **源数据核验（SDV）**：核对病历/检验结果等源文件与 CRF/EDC 录入的一致性；
2. 知情同意书核查（版本、签署日期、代签合规）；
3. 药品清点：发放、回收、销毁、温控记录与依从性；
4. 方案偏离（PD）识别、记录与上报；
5. 文档核查：ISF（研究者文件夹）完整性与版本时效；
6. 监查报告撰写（monitoring report），问题跟踪至闭环。

### 3.3 基于风险的监查（RBM）
- 按风险分层制定监查计划（关键数据/关键流程）；
- 结合中心绩效指标（KRI）动态调整监查频率；
- 结合远程监查（CTMS/EDC 数据审查）与现场监查。

### 3.4 中心关闭（Close-out）
- 完成数据澄清、文档归档、药品清点回收、关闭访视报告。

## 四、CRC（Clinical Research Coordinator）核心职责

CRC 在研究者授权与监督下开展**非医疗决策**的支持性工作：

1. **知情同意协助**：安排签署、核对版本、留存复印件（解释由研究者负责）；
2. **受试者管理**：招募筛选登记、随访日程安排、提醒与依从性沟通；
3. **数据支持**：EDC 录入、源文件整理、质疑回复（需研究者确认后提交）；
4. **科室协调**：与检验、影像、病理、GCP 办公室等多部门对接；
5. **文档管理**：受试者文件夹（IPF）完整、归档；
6. **不良事件协助**：在研究者监督下协助 SAE 报告流程；
7. **沟通桥梁**：研究者 ↔ 申办者/CRA 之间的信息传递与问题跟踪。

> ⚠️ 边界红线：CRC 不得替代研究者作出任何诊疗决定、不得独立签署知情同意、不得单独评判 AE 与疗效。

## 五、监查（Monitoring）与稽查（Audit）的区别

| 维度 | 监查 CRA | 稽查 QA |
|---|---|---|
| 归属 | 项目运营（申办者/CRO） | 质量管理（申办者独立部门，与项目组分离） |
| 目的 | 过程监督、及时纠偏 | 独立评估合规性与体系有效性 |
| 时机 | 按监查计划贯穿始终 | 关键节点/随机/风险触发 |
| 报告去向 | 项目团队 | 管理层，不直接向项目组汇报结论 |
| 关系 | 与中心日常协作 | 与中心保持独立（避免利益冲突） |

## 六、临床试验数据与安全性报告要点

1. **数据完整性**：EDC 权限管理、审计追踪、修订留痕（不得覆盖原始数据）；CRF 填写应"当场实时"完成；
2. **SAE（严重不良事件）报告**（以方案与现行法规为准）：
   - 研究者获知 SAE 后应在规定时限内（一般**24小时内**）报告申办者；
   - 申办者评估后按要求**快速报告**药监部门与伦理/机构（致死或危及生命事件通常要求首次报告后尽快补充完整报告，国际惯例 7 天/15 天，中国以法规与方案要求为准）；
   - SUSAR（可疑且非预期严重不良反应）是快速报告的重点；
3. **方案偏离（PD）/违背（PV）**：分级记录、上报伦理与机构、必要时修正方案；
4. **盲态维护**：揭盲程序严格受控，禁止计划外揭盲；
5. **文档保存**：基本文件保存期限（以 GCP 与注册法规为准，一般至少保存至药品上市后若干年或研究终止后多年）。

## 七、GCP 检查（注册核查）

- 药品注册核查（CFDI 等实施）：核查数据真实性、合规性；
- 核查重点：知情同意过程、源数据-SDV、SAE 报告、药品管理、人员资质；
- 数据造假后果：不予批准、处罚到人、行业禁入。

## 八、CRA/CRC 职业与质量管理衔接

- 常见分工进阶：CRA → 高级 CRA → 临床监查经理（CRM）；CRC → 项目协调主管；
- 临床 QA/QC 岗位：临床稽查员（Auditor）、数据质控（Data QC）、PV 专员；
- GCP 知识体系与 GxP、QA/QC（知识库13）、药物警戒（知识库08）相互衔接，构成现代药学研发质量管理全链。
