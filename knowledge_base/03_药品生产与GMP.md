# 03 药品生产与GMP

> 主题：药品生产许可、GMP 体系、质量风险管理与数据完整性。
> 参考：《药品生产质量管理规范》（2010年修订）及其附录。

## 一、药品生产管理概述

- 药品生产企业必须取得《药品生产许可证》；
- 生产的药品必须符合国家药品标准或经核准的注册标准；
- GMP 是药品生产和质量控制的**基本准则**，药品生产全过程必须符合 GMP。

## 二、GMP 核心理念

1. **质量源于设计与生产**："药品质量是设计和生产出来的，不是检验出来的"——检验只是最后把关。
2. **全过程控制**：从物料采购、生产操作、环境控制、设备维护到成品放行全程受控。
3. **文件化与可追溯**：所有操作有文件、有记录、可追溯。
4. **风险为本**：按 ICH Q9 进行质量风险管理，风险评估结果用于决策（如验证范围、环境监测频率、供应商分级）。
5. **持续改进**：自检（内审）、CAPA（纠正与预防措施）、年度质量回顾。

## 三、GMP 主要章节要素

### 3.1 质量管理
- 质量方针与质量目标；
- 质量保证（QA）：确保产品符合预期用途与质量标准；
- 质量控制（QC）：取样、检验、放行；
- 质量风险管理（QRM）：风险识别、分析、评估、控制、沟通、审核；
- 产品放行：质量受权人制度（QP，放行责任人）。

### 3.2 机构与人员
- 关键人员：企业负责人、生产管理负责人、质量管理负责人（通常要求相互独立，不得兼任）、质量受权人；
- 培训：全员岗前培训与持续培训，特殊岗位（无菌操作、取样）专项培训；
- 人员卫生：健康档案、行为规范（无菌区着装要求）。

### 3.3 厂房与设施
- 分区：生产区、仓储区、质量控制区、辅助区；
- 洁净级别：A/B/C/D 级（ISO 14644 对应），无菌工艺要求；
- 防止污染与交叉污染：人流物流分离、专用生产设施、压差梯度、HVAC 系统。

### 3.4 设备
- 设计、选型、安装、调试符合工艺需要；
- 校准、维护、清洁验证（残留限度）；
- 设备状态标识、使用记录。

### 3.5 物料与产品
- 供应商评估与批准（供应商审计）；
- 物料接收、标识、储存（温湿度条件、效期管理）；
- 取样与检验、放行与拒收；
- 成品：入库、储存、发运条件。

### 3.6 生产管理
- 批生产记录（BPR）、批号管理；
- 防止污染与混淆：清场管理、状态标识、双人复核；
- 生产时限、中间产品控制、收率偏差调查；
- 包装与贴签操作（防混淆）。

### 3.7 质量控制
- 检验方法验证/确认；
- 稳定性试验（长期、加速、影响因素）；
- 留样管理、持续稳定性考察。

### 3.8 验证
- 验证总计划（VMP）：工艺验证、清洁验证、设备验证、分析方法验证、计算机化系统验证；
- 变更后验证、周期性再验证。

### 3.9 变更控制、偏差与 CAPA
- 变更控制：评估影响、批准、实施、验证、关闭；
- 偏差处理：发现→评估→调查→纠正/预防措施→关闭；
- 纠正与预防措施（CAPA）：根本原因分析（鱼骨图、5Why）。

### 3.10 数据完整性（ALCOA+）
- Attributable（可归属）、Legible（清晰）、Contemporaneous（同步）、Original（原始）、Accurate（准确）；
- + Complete（完整）、Consistent（一致）、Enduring（持久）、Available（可获得）；
- 计算机化系统：权限管理、审计追踪、备份。

## 四、无菌药品生产要点

1. 无菌工艺模拟试验（培养基灌装）；
2. 除菌过滤与无菌操作（B+A 环境）；
3. 灭菌工艺验证（过度杀灭法/残存概率法）；
4. 环境监测：悬浮粒子、浮游菌、沉降菌、表面微生物；
5. 最终灭菌产品与无菌生产产品的工艺区别。

## 五、企业与持有人关系（委托生产）

- 持有人可以委托生产，但应**全程监督**受托企业，签订质量协议；
- 持有人对产品的最终质量负责，负责上市放行；
- 受托企业不得将受托产品再次委托他人生产。

## 六、GMP 检查与认证

- 生产许可检查（按 GMP 标准）；
- 日常监管：跟踪检查、飞行检查；
- 检查风险点：数据完整性、验证真实性、偏差调查是否闭环、人员培训是否流于形式。
