# 06 处方与调剂管理

> 主题：《处方管理办法》（2007年卫生部令第53号）要点：处方标准、权限、调剂"四查十对"、处方点评与保存。
> 参考：蚌埠市政府网转载《处方管理办法》全文等公开文本。

## 一、处方概述

处方是医师为患者预防、治疗疾病开具的、由药学专业技术人员审核、调配、核对，并作为患者用药凭证的医疗文书，也是医疗责任的法律文书。

### 处方标准（前记、正文、后记）

- **前记**：医疗机构名称、患者姓名、性别、年龄、门诊/住院病历号、科别或病区和床位号、临床诊断、开具日期、医师与药师签名；麻醉药品和第一类精神药品处方还应载明患者身份证明编号、代办人信息等。
- **正文**：药品名称、剂型、规格、数量、用法用量；每张处方不得超过**5种药品**（同品种注射剂/口服剂各算1种）；须注明临床诊断（特殊情形除外）。
- **后记**：医师签名或加盖专用章，药品金额，审核/调配/核对/发药药师签名。

## 二、处方书写规则要点

1. 使用规范的中文名称书写，药品名称以《中国药典》或通用名称为准；
2. 剂量、数量用阿拉伯数字，单位规范（g、mg、μg、ml、U 等）；
3. 用法用量应准确规范，注明每次用量与给药途径；
4. 处方字迹清楚、不得涂改；如需修改，应在修改处签名并注明修改日期；
5. 西药、中成药可分别开具，也可开具一张处方；中药饮片应单独开具；
6. 特殊药品处方应用相应颜色（麻醉药品、第一类精神药品用**红色**处方，第二类精神药品用**白色**处方并标注——以现行规定为准）；
7. 计算机打印处方与手写处方具有同等效力，电子处方须符合规定并可追溯。

## 三、处方权限

- 注册执业医师、执业助理医师在执业地点取得**处方权**；
- 医师签名（签章）留样于本机构药学部门备案；
- 特殊药品处方权：麻精药品处方权须经培训考核合格授予；
- 药师（卫生技术人员）经本机构考核合格取得**处方调剂资格**后，方可调剂处方；
- 开具处方的医师与调剂药师不得为同一人（本院规定）。

## 四、处方有效期与用量（一般规定）

1. **有效期**：处方当日有效；特殊情况下需延长有效期的，由开具处方的医师注明有效期限，但最长不得超过**3天**。
2. **一般用量**：
   - 门诊普通处方：一般不得超过**7日**用量；
   - 急诊处方：一般不得超过**3日**用量；
   - 慢性病、老年病或特殊情况下可适当延长用量，但医师应当注明理由；
   - 麻醉药品和第一类精神药品：注射剂每张处方为**一次常用量**；控缓释制剂不得超过**7日**用量；其他剂型不得超过**3日**用量；第二类精神药品一般每张处方不得超过**7日常用量**（住院患者另有规定）。
3. 处方用量超常时药师应予以干预并登记。

## 五、调剂"四查十对"（核心考点）

药师调剂处方时必须做到"四查十对"：

1. **查处方**，对科别、姓名、年龄；
2. **查药品**，对药名、剂型、规格、数量；
3. **查配伍禁忌**，对药品性状、用法用量；
4. **查用药合理性**，对临床诊断。

## 六、处方审核要点

药师审核处方应包括：
1. **合法性**：医师处方权、处方形式（签名/印章备案）、特殊药品处方资格；
2. **规范性**：前记正文后记完整、分类正确、颜色规范、字迹清晰、无涂改；
3. **适宜性**：
   - 规定必须做皮试的药品是否注明过敏试验及结果；
   - 处方用药与临床诊断的相符性；
   - 剂量、用法的正确性（儿童、老人、肝肾功能不全者剂量调整）；
   - 选用剂型与给药途径的合理性；
   - 是否有重复给药、相互作用、配伍禁忌；
   - 是否存在禁忌症；
   - 妊娠期、哺乳期用药风险评估。

**用药适宜性审核认为存在用药不适宜时，应当告知处方医师，请其确认或者重新开具处方；药师发现严重不合理用药或者用药错误，应当拒绝调剂，及时告知处方医师，并应当记录，按照有关规定报告。**

## 七、调配与发药

1. 调配药品时认真核对、按照操作规程调剂；
2. 药品发出前由另一药师（或复核岗）核对（双人核对）；
3. 发药时进行**用药交代**：用法用量、注意事项、储存条件、不良反应预警；
4. 拆零药品保留说明书复印件/电子说明，标注有效期。

## 八、处方点评制度

依据《医院处方点评管理规范（试行）》（2010）：
- 处方点评组织：医院药学部门与医务部门共同组织，成立处方点评专家组；
- 点评对象：门诊处方、急诊处方、住院医嘱；
- 抽样：门急诊处方每月不少于**100张**（或不少于总处方量的1‰）；病区医嘱每月不少于**30份**；
- 结果：合理处方 / 不合理处方（用药不适宜处方、超常处方等）；
- 超常处方警告：无正当理由超说明书用药、无适应证用药等；
- 点评结果与绩效考核、医师处方权管理挂钩。

## 九、处方保存期限

| 处方类型 | 保存期限 |
|---|---|
| 普通处方、急诊处方、儿科处方 | 1年 |
| 医疗用毒性药品处方、第二类精神药品处方 | 2年 |
| 麻醉药品和第一类精神药品处方 | 3年 |

处方保存期满后，经医疗机构主要负责人批准、登记备案，方可销毁。

## 十、电子处方与互联网诊疗

- 互联网诊疗开具的电子处方须由**经实名认证的执业医师**开具；
- 电子处方经药师审核后方可调配；
- 通过网络销售的处方药须"先方后药"，药品零售企业提供药学服务；
- 电子处方保存与调阅应符合医疗机构病历管理规定。
