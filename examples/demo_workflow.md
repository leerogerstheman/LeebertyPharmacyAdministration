# 综合案例：药企 GSP 合规建设全流程（对应 hello-agents 第13章 多工具综合案例）

> 演示 Agent 一次会话内如何组合身份切换、法规模块、自查工具、经济学计算器与模板服务。
> 操作路径：桌面应用或 Web 输入以下指令序列。

## 案例剧本：新开办药品批发企业的合规起步

**Step 1 身份设定（调度器路由）**
```
用户：我是公司
Agent：您好！我是贵企业的合规顾问。可协助：GSP/GMP 合规自查、经营许可申办、药物警戒体系、药品追溯、冷链管理等。
```

**Step 2 法规速查（law_lookup 工具 / kb_search）**
```
用户：药品经营许可证办理条件有哪些？
Agent：命中《04_药品经营与GSP》·一 药品经营概述 + GSP 总则要点……（来源标注）
```

**Step 3 合规自查（checklist_router 交互式清单）**
```
用户：GSP自查
Agent：[1/12] 许可证在有效期内，经营范围与实际经营一致？（逐项回答 是/否）
用户：是 / 否 ×12 → 通过率与整改项报告
```

**Step 4 经济学评估（icer_calc 计算器）**
```
用户：自营配送成本10000元效果8，第三方物流15000元效果9，哪个划算？
Agent：ΔC=5000，ΔE=1，ICER=5000 元/单位效果 ≤ 阈值 80000 → 第三方物流具有成本效果……（计算过程完整展示）
```

**Step 5 制度建设（template_list 模板）**
```
用户：模板
Agent：制度汇编 / 处方审核记录 / 不良反应报告表 / 年度培训计划（可直接复用）
```

**Step 6 深度研究（第14章 research 模式，可选）**
```
用户：深度研究 冷链药品管理合规
Agent：多关键词检索（冷链/药品储存运输/验证）→ 结构化报告（背景/要点/风险/建议）
```
