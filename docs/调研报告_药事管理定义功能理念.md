## 一、药事管理的定义

### 1.1 药事（Pharmaceutical Affairs）的内涵

药事是指**与药品安全、有效、合理、方便、经济、及时使用相关的全部活动**，包括：药品的研发、制造、采购、储藏、营销、运输、交易中介、服务、使用等活动，还包括与药品价格、药品储备、医疗保险有关的活动。

（来源：首都医科大学宣武医院药剂科《药事管理》课程讲义，华医网：https://v8.91huayi.com/cme/201009194687/05/jiangyi/content.html）

### 1.2 药事管理的定义

**药事管理**是指：为保障公民用药的**安全、有效、合理、经济、方便、及时**，国家依据宪法，通过制定并实施相关法律法规，以及药事组织（药品研制、生产、经营、使用单位等）实施相关管理措施，对药事活动进行必要的监督管理。

- **宗旨**：保障公民用药安全、有效、经济、合理、方便、及时，不断提高国民健康水平，不断提高药事组织的经济、社会效益水平。
- **管理依据**：宪法与法律（如《中华人民共和国药品管理法》）。
- **管理手段**：政府制定法律法规 + 药事组织内部管理措施。

### 1.3 两个层面

| 层面 | 主体 | 内容 |
|---|---|---|
| 宏观药事管理 | 国家和政府 | 药品监督管理、基本药物管理、药品储备管理、药品价格管理、医疗保险用药与定点药店管理 |
| 微观药事管理 | 药事组织内部 | 药品研发质量管理、药品生产质量管理、药品经营质量管理、药学服务质量管理、药品临床试验质量管理 |

宏观管理为微观管理提供法律依据、标准和程序。

### 1.4 药事管理的特点

1. **专业性**：是对药学事业的管理，核心是药物——防病治病、保障公众健康的物质基础。
2. **政策性**：按照国家法律、政策法令和行政规章行使国家权力进行管理。
3. **实践性**：法规与规章来源于生产、经营、使用实践，经总结升华后反过来指导实践。

### 1.5 药事管理体制

指一定社会制度下药事系统的组织方式、管理制度和管理方法，包括：药品质量监督管理体制、药品生产经营管理体制、药品使用管理体制、药学教育管理体制和科技管理体制。

## 二、药事管理的功能（依主体划分）

### 2.1 国家/政府层面（宏观监管功能）

1. 药品注册审批与上市后监管（NMPA 及其派出机构、省级药监部门）
2. 药品质量标准制定（《中国药典》）
3. 药品经营许可（批发/零售）与监督检查、飞行检查
4. 药品不良反应监测与药物警戒制度推行
5. 基本药物制度、国家医保目录、集中带量采购
6. 特殊药品（麻醉药品、精神药品、毒性药品、放射性药品）管制
7. 药品追溯体系建设
8. 药品安全信用与稽查执法

### 2.2 药品研制/生产/经营企业（微观管理功能）

- **研发质量管理**：GLP、GCP、ICH 指导原则
- **生产质量管理**：GMP（质量风险管理、偏差、变更、验证、数据完整性）
- **经营质量管理**：GSP（采购、验收、储存、养护、销售、运输、追溯）
- 不良反应报告主体责任（MAH 直接报告制度）

### 2.3 医疗机构（药事管理功能）

1. 组织管理：药学部门组织体制、人员配备与岗位职责
2. 药品供应管理：采购、验收、贮存、供应、效期与冷链管理
3. 调剂业务管理：处方审核、调配、发药规范（四查十对）
4. 药品质量与监督管理：药品检验、特殊管理药品监督
5. 临床药学管理：用药安全性、有效性、合理性评价与不良反应监测
6. 药物信息管理：为医师、护士、患者提供用药咨询服务
7. 经济管理：账务管理与成本核算

### 2.4 药事管理与药物治疗学委员会职责（二级以上医疗机构）

1. 贯彻《药品管理法》等法规，制定本机构药事管理规章制度并监督实施
2. 确定本机构用药目录和处方手册
3. 审核拟购入药品的品种、规格、剂型；审核新制剂配制及新药临床观察申请
4. 建立新药引进评审制度，组织新药引进评审
5. 定期分析药物使用情况，评价临床疗效与安全性，提出淘汰品种意见
6. 检查毒、麻、精神及放射性药品的使用管理情况
7. 组织药学教育培训，监督指导临床合理用药
8. 编辑出版本机构药品信息通讯

（来源：同上华医网讲义）

## 三、药事管理的理念

1. **以患者为中心**：从"对物的管理"转向"对人的用药管理"，以患者合理用药为重心。
2. **安全第一**：保障公众用药安全是药事管理的首要目标（用药安全、有效、经济、合理、方便、及时）。
3. **依法治理**：依据宪法、法律、行政法规、部门规章实施管理。
4. **全生命周期管理**：从研发、注册、生产、流通到使用、上市后监测的全链条管理。
5. **质量源于设计（QbD）与风险管理**：GMP 强调"质量是设计和生产出来的，不是检验出来的"；ICH Q9 质量风险管理贯穿始终。
6. **社会共治**：政府监管、企业自律、行业自治、公众参与相结合。
7. **循证决策**：以药事数据、临床证据、药物经济学评价支撑用药目录与医保决策。

## 四、主要法律法规框架（知识要点）

| 层级 | 名称 | 要点 |
|---|---|---|
| 法律 | 《药品管理法》（2019修订） | 药品上市许可持有人（MAH）制度、药品追溯、不良反应监测报告、临床试验默示许可、附条件批准、药品安全信用档案 |
| 法律 | 《疫苗管理法》 | 疫苗全生命周期最严格管理 |
| 行政法规 | 《药品管理法实施条例》 | 药品管理法实施细则 |
| 行政法规 | 《麻醉药品和精神药品管理条例》 | 麻精药品生产、经营、使用管制；医疗机构"五专"管理 |
| 行政法规 | 《医疗用毒性药品管理办法》《放射性药品管理办法》 | 特殊药品管理 |
| 部门规章 | 《药品经营质量管理规范》（GSP，2016修订） | 药品批发与零售质量管理准则 |
| 部门规章 | 《药品生产质量管理规范》（GMP） | 药品生产质量管理准则 |
| 部门规章 | 《处方管理办法》（2007） | 处方标准、权限、调剂"四查十对"、处方点评、处方保存 |
| 部门规章 | 《医疗机构药事管理规定》（2011） | 药事管理与药物治疗学委员会、药学部门职责 |
| 部门规章 | 《药品不良反应报告和监测管理办法》（2011） | 不良反应报告范围、时限、评价与控制 |
| 规范性文件 | 《药物警戒质量管理规范》（GVP，2021年12月1日施行） | 药品上市许可持有人药物警戒体系要求 |
| 规范性文件 | 《抗菌药物临床应用管理办法》 | 抗菌药物分级管理、处方权限 |

**调剂的"四查十对"**（《处方管理办法》第37条）：
- 查处方，对科别、姓名、年龄；
- 查药品，对药名、剂型、规格、数量；
- 查配伍禁忌，对药品性状、用法用量；
- 查用药合理性，对临床诊断。

**医疗机构对麻精药品的管理（五专）**：专人负责、专柜加锁、专用账册、专用处方、专册登记。

（来源：河南药师网 GSP 全文 http://www.hnysw.org/index/index/news_content.html?news_id=427；安徽卫健委"五专管理"质控标准 https://wjw.ah.gov.cn/group4/M00/02/A4/wKg862GA7V6AQH88ABW9F_5hXJA149.pdf；蚌埠市政府《处方管理办法》全文 https://www.bengbu.gov.cn/group1/M00/0B/32/wKgQFmGI5VaAWFVxAAOdvWsBO-M773.pdf；全国人大网关于药品管理法修改说明 http://www.npc.gov.cn/wxzlhgb/c27214/c36614/201912/P020230313538943912431.pdf）

## 五、药学服务理念（Pharmaceutical Care）

- 1990 年 Hepler & Strand 提出 **Pharmaceutical Care（药学监护/药学服务）**：药学人员以负责任的态度提供药物治疗，以达到明确改善患者生活质量为既定结果的直接、负责的与药物有关的照顾。
- 现代医院药事管理重心：从药品供应保障转向**以患者为中心的药学服务**，包括处方审核、用药教育、药物咨询、药物重整、慢病用药管理、药物治疗管理（MTM）、基因药物经济学应用等。
- WHO 合理用药标准：**适当、有效、安全、经济**。
